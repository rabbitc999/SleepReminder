# ? 睡眠提醒器 (SleepReminder)

一款专为“夜猫子”设计的全屏强制提醒工具，通过霸屏警告和关机/延后功能，帮助用户规律作息，减少熬夜危害。

---

## ? 主要功能

- **区间定时提醒**  
  用户可设置开始和结束时间（支持跨天，如 23:50 ~ 07:00），程序在区间内每日触发一次全屏提醒。

- **霸屏强制提醒**  
  提醒时全屏置顶、无边框、无法通过 Alt+F4 或任务管理器关闭（生产模式下自动杀死 `taskmgr.exe`）。

- **关机 & 延后**  
  提醒窗口提供“关机”按钮（带二次确认）和“延后10分钟”功能（每天仅一次，倒计时结束后自动恢复）。

- **开机自启动**  
  通过托盘菜单轻松启用/禁用，支持“启动文件夹”方式（无需管理员权限，更可靠）。

- **单例运行**  
  防止重复启动，生产模式下只允许一个实例运行，再次启动会激活已有窗口。

- **调试模式**  
  当附加调试器（如 Visual Studio）时，自动切换为普通窗口，方便开发和调试。

## ? 安装与使用

### 1. 下载发布版本
从 [Releases](https://gitee.com/embed2026/sleep-remider/releases) 页面下载最新版的 `SleepReminder.exe`，双击运行即可（程序会自动隐藏到系统托盘）。

### 2. 手动构建（开发环境）
- 使用 Visual Studio 2019+ 打开 `SleepReminder.sln`
- 还原 NuGet 包（如有）
- 选择 `Release` 配置，生成解决方案
- 生成的可执行文件位于 `bin\Release\` 目录

### 3. 首次使用
- 点击系统托盘图标 → “设置提醒时间”，选择你期望的提醒区间。
- 通过托盘菜单启用“开机自启动”（推荐）。
- 到点后，全屏提醒将自动弹出。

---

## ?? 设置说明

| 功能 | 操作路径 |
|------|----------|
| 设置提醒区间 | 托盘菜单 → “设置提醒时间” |
| 启用/禁用开机自启 | 托盘菜单 → “启用开机自启动” / “禁用开机自启动” |
| 退出程序 | 提醒窗口左下角“退出”按钮（需连续确认10次）或托盘菜单“退出程序” |
