# 💤 睡眠提醒器 (SleepReminder)

一款专为“夜猫子”设计的全屏强制提醒工具，通过霸屏警告、数学答题验证和关机/延后功能，帮助用户规律作息，减少熬夜危害。

## ✨ 主要功能

- **区间定时提醒**  
  用户可设置开始和结束时间（支持跨天，如 23:50 ~ 07:00），程序在区间内每日触发一次全屏提醒。

- **霸屏强制提醒**  
  提醒时全屏置顶、无边框、无法通过 Alt+F4 或任务管理器关闭（生产模式下自动杀死 `taskmgr.exe`）。

- **智能答题关闭**  
  点击“关闭提醒”按钮，弹出答题窗口，需完成 **10 道随机算术题**（三位数×两位数、四/五位数÷两位数、五位数加减法）和 **1 道终极 Boss 题**（从字母数字混合串中提取所有质数）。全部答对方可关闭提醒，任意一题答错则本次关闭机会永久取消。

- **延后 10 分钟**  
  点击“延后”按钮可暂时退出霸屏（无需答题），10 分钟后自动恢复提醒（调试模式为 10 秒）。每天仅可使用一次延后。

- **关机功能**  
  提供“关机”按钮，点击后二次确认，立即关闭系统。

- **防作弊机制**  
  - 答题期间自动杀死计算器进程（`calc.exe` / `Calculator.exe`），防止使用计算器作弊。
  - 生产模式下持续杀死任务管理器（`taskmgr.exe`），阻止用户强制结束程序。

- **开机自启动**  
  通过托盘菜单轻松启用/禁用，采用“启动文件夹”方式（无需管理员权限，更可靠）。

- **单例运行**  
  防止重复启动，生产模式下只允许一个实例运行，再次启动会激活已有窗口。

- **调试模式**  
  当附加调试器（如 Visual Studio）时，自动切换为普通窗口，算术题减为 1 道，延后时长缩短为 10 秒，方便开发和测试。

## 📦 安装与使用

### 1. 下载发布版本
从 [Releases](https://gitee.com/rabbitc999/sleep-remider/releases) 页面下载最新版的 `SleepReminder.exe`，双击运行即可（程序会自动隐藏到系统托盘）。

### 2. 手动构建（开发环境）
- 使用 Visual Studio 2019+ 打开 `SleepReminder.sln`
- 还原 NuGet 包（如有）
- 选择 `Release` 配置，生成解决方案
- 生成的可执行文件位于 `bin\Release\` 目录

### 3. 首次使用
- 点击系统托盘图标 → “设置提醒时间”，选择你期望的提醒区间。
- 通过托盘菜单启用“开机自启动”（推荐）。
- 到点后，全屏提醒将自动弹出。

---

## ⚙️ 设置说明

| 功能 | 操作路径 |
|------|----------|
| 设置提醒区间 | 托盘菜单 → “设置提醒时间” |
| 启用/禁用开机自启 | 托盘菜单 → “启用开机自启动” / “禁用开机自启动” |
| 关闭提醒（需答题） | 点击提醒窗口中间的“关闭提醒（需答题）”按钮，完成算术题和 Boss 题 |
| 延后 10 分钟 | 点击提醒窗口左上角“延后 10 分钟”按钮（无需答题） |
| 关机 | 点击提醒窗口右下角“关机”按钮（二次确认） |
| 退出程序 | 托盘菜单 → “退出程序”（需连续确认 10 次） |
