# 💤 睡眠提醒器 (SleepReminder)

一款专为“夜猫子”设计的全屏强制提醒工具：到点霸屏、**延后要“借款”**、而且**没有任何界面退出入口**。
它用一个**额度账本**管住你的“再玩十分钟”——固定额度每夜白送、附加额度按周回补，
宽松夜打折、超支要还；再配上一本能随时翻阅的“额度与作息预览”，让规则明明白白摆在桌面上。

## ✨ 主要功能

### ⏰ 区间定时提醒
用户可设置开始与结束时间（**支持跨天**，如 `23:30 ~ 07:00`），程序在区间内每日触发一次全屏提醒。
提醒时间属于“真需求”，**可随时修改、不受任何限制**。

### 🖥️ 霸屏强制提醒
提醒时全屏置顶、无边框、`Alt+F4` 关不掉；生产模式下持续结束任务管理器进程（`taskmgr.exe`），
阻止用户强行关闭。主程序被结束也会被守护进程重新拉起（见下方“守护与自愈”）。

### 💳 借贷式延后额度（核心机制）
“延后”不再按**次数**限制，而是按**总量**放贷 —— 额度分两层：

- **固定额度**：每夜白送 **10 分钟**，跨夜重置、**不可累积**（攒着不花等于鼓励提前熬夜）。
- **附加池（两个）**：**休息池**与**工作池**，各自滚动 7 天、默认容量各 **60 分钟**；
  只有固定额度花完了才动得了它，而且**只能动本夜对应的那一个**。

额度还会按“夜”的类型浮动，而**判据只有一个：明天要不要上班**：

- **宽松夜**（次日不用上班，含周五夜、周六夜、长假前夜）：附加消耗打 **五折**，从**休息池**支取；
- **紧张夜**（次日要上班，含调休补班的周五夜、单休制下的周五夜）：**系数 1.0**，全额照扣，从**工作池**支取。

两个池**互不挤占**：周末挥霍掉的只会是休息池，工作日那份额度原样留着；
各自的滚动 7 天窗口内只统计同型夜，用量与余额分别计算。

单夜另有封顶：紧张夜 **30 分钟**、宽松夜 **60 分钟**，免得某个失控的夜晚把一周的池子抽干。
节假日、调休、大小周、单休，全部交给内置日历自动判定（见下方“工作日日历”）；
**待业模式**下每天都是放假，于是夜夜都是宽松夜。

> **账本怎么读**：预览窗口左栏的「延后」是本夜**累计**延后了多少时长，「池扣」只是其中**真正动用本夜所属池**的部分。
> 例：单夜延后 20 分钟 = 固定额度的 15 分钟（不扣池）＋ 超出部分 5 分钟（按夜系数计入池）。
> 所以「池扣 5:00」**不代表**「只扣了 5 分钟」，两者之差就是固定额度那个白送的口子。
> 时长一律按 `mm:ss` 显示，满一小时进位为 `H:mm:ss`。

**账不会丢**：延后按“夜”结算，**关机 / 重启即为一夜的终点**。

- 倒计时**正常走完** → 按实际经过**秒数**入账；
- 被**强杀 / 关机 / 注销** → 下次启动时**对账补记**：取 `max(最后心跳, 系统记录的上次关机时刻)`
  作为结算时刻。自己写的账本可以抹掉，系统注册表里的 `ShutdownTime` 抹不掉。

两条路**互斥**、都会清掉同一个“延后中”锚点，因此**同一次延后只会结算一次**，绝不会重复扣费。

**账以秒为单位记**：从结算到对账补记，全按实际经过的**秒数**入账，不做任何分钟级取整。
早先按分钟记账时，“延后 1 分 59 秒就点返回”会被向下取整成 1 分钟——每次白送 59 秒，
反复操作就能无限延后而不入账。现在跑多少秒就记多少秒，这条缝没有了。
账本存于 `LedgerNightLogSec`；旧键 `LedgerNightLog`（分钟级）会在首次读取时按 ×60 一次性迁移，
迁移后删除旧键，**一笔不丢、也不会放大两次**。

进入提醒时，屏幕**右上角**会实时显示额度摘要，用词与“设置”窗口一致，且明确标出**剩多少**：
`固定额度剩 09:30 ｜ 休息池剩 42:00 ｜ 宽松夜（系数 0.5）`（池名随夜型变化，紧张夜显示「工作池」）。

**延后倒计时窗口里的固定额度是“真”的**：点“延后保存数据”后弹出的倒计时小窗里，大号数字是
**本次延后的剩余时间**，它下面那行橙色数字是本夜**固定额度的真实余额**（`固定额度剩 07:23`）——
随本次延后**逐秒递减**，扣到 `00:00` 才开始动用本夜所属的池（此时摘要里会标出“已开始支取”）。
再下面一行是池余额与本夜类型。这三行都由“本次已流逝秒数”实时算出，
**倒计时归零时显示的余额与随后结清入账的账本一致**；投影本身不写账，所以同一次延后仍然只计一次费。

**这个窗口可以拖着走**：按住窗口任意位置拖动即可挪到不挡视线的地方（顶部有一道灰色把手提示可拖），
**双击回到默认的屏幕右上角**。窗口没标题栏也没关闭按钮，拖动只改位置，不影响倒计时与计费。
窗口底部还有一个 **“返回提醒页”**：提前收起小窗、回到黑色霸屏提醒页——
已经流逝的时间**照常按秒记进账本**（走的就是倒计时走完那条结算路径，不会重复计费），
剩余时间既不白送也不预扣，只是不再把倒计时耗完。

### ⚙️ 统一的“设置”窗口
托盘菜单里的“设置”把三组参数收进同一个窗口：

| 分组 | 内容 | 修改限制 |
|------|------|----------|
| 提醒时间 | 开始 / 结束时间（跨天） | **随时可改** |
| 延后时长 | 单次延后分钟数（5 ~ 15） | **随时可改** |
| 额度与周制 | 周制（双休 / 单休 / 大小周 / 待业）、固定额度、休息池、工作池、夜系数、单夜封顶、是否透支 | **每个自然周只能改一次** |

额度组受“每周一次”的锁保护——免得当晚额度见底就临时调大；锁定期该组控件整体置灰，
但提醒时间与延后时长照常可改。把“真需求”和“放贷杠杆”分开，机制才算讲道理。
**待业模式也在这一组**：它把每一夜都变成宽松夜，等于放宽了惩罚力度，因此同样受这道锁约束。

### 📊 额度与作息预览
托盘菜单“预览”打开一个只读窗口：

- **左栏（额度）**：今夜归属、夜型与系数、本夜已延后、固定额度余额、**休息池与工作池**在各自
  滚动 7 天窗口内的用量与余额、此刻最多还能延后多少、设置锁状态、累计违约次数，以及**近 7 夜的逐夜明细**。
- **右栏（作息）**：从今天起 **21 天**的“上班 / 休息”，并标出**判定依据**
  （法定放假 / 调休·单位安排上班 / 按周制作息 / 待业模式），今日高亮，方便核对单休、大小周与调休。
- **底部**：只有一个“刷新”按钮。关闭预览直接点窗口右上角即可（预览是**只读**窗口，不含任何退出入口）。
- **延后倒计时小窗**：同样没有关闭按钮，但**可以拖着走**（按住任意处拖动，双击回位）。

### 🎨 自定义提醒外观
提醒页支持改造成你自己的样子：**背景图片（可选）+ 大标题 + 小标题 + 条目正文**（每行一条），
改完**立即生效**。背景图会叠一层半透明遮罩，保证前景文字始终清晰；未设图或图片读取失败时，
自动退回纯色背景，不会因为一张图挂掉整个提醒。

### 🔒 没有任何退出入口
提醒页与预览窗口里都**没有退出按钮**了——“退出(需答题)”与预览窗口的“退出程序”均已移除。
想离开霸屏，只剩两条路：**“延后保存数据 / 稍后继续”**（消耗额度）或**“关机”**（二次确认）。

需要停用程序时（维护 / 升级），请用 [`autorestart/`](autorestart/) 下的 `uninstall.cmd`
卸载看门狗，再结束进程；否则守护进程会把主程序重新拉起来。日常覆盖升级直接用 [`deploy.ps1`](deploy.ps1) 即可。

### 🔌 关机
警告页右下角“关机”按钮，二次确认后立即关闭系统。

### 🚀 开机自启动
程序启动时自动把自身写入注册表启动项（`HKCU\...\CurrentVersion\Run`），**无需管理员权限**。
如不再需要，可在“任务管理器 → 启动”里禁用它。

### 🛡️ 守护与自愈
主进程被结束会被立刻拉起：主程序以 `--daemon --pid=<主进程号>` 派生一个**守护进程**，
再用计划任务 “SleepReminder Watchdog” 把守护进程也盯住。相关脚本与安装 / 卸载 / 查看状态的
命令都在 [`autorestart/`](autorestart/) 目录里（`install.cmd` / `uninstall.cmd` / `status.cmd` 等）。

### 🧪 单例运行 & 调试模式
- **单例运行**：同时只允许一个实例，重复启动会激活已有窗口。
- **调试模式**：附加调试器时自动切换为普通窗口、延后时长缩短为 10 秒，
  且**不写额度账本**，方便开发与测试（每次启动都是全新状态）。

### 🗓️ 工作日日历（节假日 / 调休 / 单休 / 大小周 / 待业）
“宽松夜”与作息预览都依赖它。判定优先级为：
**待业模式 > 调休上班表 > 法定放假表 > 周制推演**。
内置数据取自国务院办公厅 2026 年放假安排；放假安排每年公布一次，因此程序还会在
**exe 同目录**寻找 `holidays.txt` 做增量覆盖，当年缺数据时会在启动时生成模板并提示补全。格式：

```
# 注释行以 # 开头
2026-10-01,R    # R = 休息（法定放假）
2026-10-10,W    # W = 上班（调休）
```

### 🛋️ 待业模式（每天都是放假）
“设置 → 额度与周制”里的周制选到 **“待业（每天都是放假）”** 后，整套作息判定让位给一个事实：
**明天不用上班**。于是：

- 任何一天都被判为休息，作息预览右栏会逐日标出依据 **“待业模式（每天放假）”**；
- **每一夜都是宽松夜**——夜系数取 0.5、单夜封顶取 60 分钟，与长假前夜同等待遇；
- **调休上班表与法定放假表都不参与判定**：待业中不存在“单位安排上班”这件事，
  所以以前补记的补班日期不会莫名其妙把某个夜晚变回紧张夜；切回正常周制后它们立刻恢复生效（数据没被动过）；
- 节假日数据维护也一并静音：不会再催你补 `holidays.txt` 的年度模板，换回双休 / 单休 / 大小周后照常提示。

注意它是**周制的一个取值**，因此和其他周制一样受“每个自然周只能改一次”的锁约束——
它放宽的是惩罚力度，不是“真需求”。

## 📦 安装与使用

### 1. 下载发布版本
从 [Releases](https://gitee.com/rabbitc999/sleep-remider/releases) 页面下载最新版的 `SleepReminder.exe`，
双击运行即可（程序会自动隐藏到系统托盘）。

### 2. 手动构建 / 部署（开发环境）
- 需要 [.NET 8 SDK](https://dotnet.microsoft.com/download)
- 构建：在仓库根目录执行 `dotnet build -c Release`
- 一键部署到正式目录 `D:\SleepReminder`：使用仓库自带的 [`deploy.ps1`](deploy.ps1)
  （构建 Release → 暂停看门狗 → 替换产物 → 启动新版 → 恢复看门狗）

### 3. 首次使用
- 点击系统托盘图标 → “设置”，调整提醒时间、延后时长与额度周制。
- 托盘图标 → “预览”，随时查看额度账本与近期作息。

## ⚙️ 设置说明

| 功能 | 操作路径 |
|------|----------|
| 查看额度与作息 | 托盘菜单 → “预览” |
| 修改设置（提醒时间 / 延后时长 / 额度与周制） | 托盘菜单 → “设置” |
| 自定义提醒外观（背景图与文字） | 托盘菜单 → “提醒外观” |
| 延后（从额度里“借款”） | 点击提醒页**左上角**“延后保存数据”按钮 |
| 稍后继续（重新弹出倒计时小窗） | 点击提醒页**左上角**“稍后继续”按钮（在延后按钮下方） |
| 收起倒计时小窗、回到霸屏 | 点击倒计时小窗底部的“返回提醒页”（已延后的部分照常记账） |
| 挪动倒计时小窗 | 按住小窗任意处拖动；双击回到屏幕右上角 |
| 关机 | 点击提醒页**右下角**“关机”按钮（二次确认） |
| 停用程序（维护 / 升级） | 界面里**没有退出入口**；用 `autorestart/uninstall.cmd` 卸载看门狗后结束进程，或用 `deploy.ps1` 覆盖升级 |

> 提醒页与预览窗口都没有“退出”按钮：**只能**靠延后或关机离开霸屏。

> 提示：额度设置**每个自然周只能改一次**；提醒时间与延后时长不受此限制。
